Linked views

A click in a Masque widget updates its @bind variable, and cells that use the variable respond to the change. So linking a scatter to a detail plot, a table, or a model fit is ordinary Pluto code: use pick in another cell to create a plot or compute a result.

Click a point in the xy plot below, and the same sample is selected in the xz plot:

Notebook as text

Click a point in the xy plot, and the same sample is selected in the xz plot. Hover stays on the plot under the pointer.

Plot the same samples, in the same order, in two figures. The xy figure stores the click in pick.

begin
    xs = [1.0, 2.0, 3.0, 4.0]
    ys = [2.0, 1.5, 3.0, 2.2]
    zs = [0.8, 2.5, 1.2, 3.1]
    fig_xy = Figure(size = (420, 280))
    ax_xy = Axis(fig_xy[1, 1]; xlabel = "x", ylabel = "y", title = "xy")
    scatter!(ax_xy, xs, ys; markersize = 18)
    nothing
end
@bind pick masque(fig_xy)

This cell uses pick and passes the clicked index as selected, so the xz plot highlights the sample you clicked.

begin
    fig_xz = Figure(size = (420, 280))
    ax_xz = Axis(fig_xz[1, 1]; xlabel = "x", ylabel = "z", title = "xz")
    scatter!(ax_xz, xs, zs; markersize = 18)
    masque(fig_xz; selected = isnothing(pick) ? Int[] : [pick.index])
end

The xz plot follows clicks, not hovering: hovering a point highlights it only on the plot under the pointer. To highlight a whole series on every plot as you hover, use a legend, as shown in Highlight a series across panels.

Drive a second plot from a click

Give each payload a key that identifies its row, such as an id or a name, and use the key in other cells. Here, clicking a city on a map plots that city's series:

begin
    cities = [
        (id = "tok", name = "Tokyo", lon = 139.7, lat = 35.7),
        (id = "del", name = "Delhi", lon = 77.2, lat = 28.6),
        (id = "sha", name = "Shanghai", lon = 121.5, lat = 31.2),
    ]
    series = Dict(
        "tok" => [3.1, 3.4, 3.2, 3.6],
        "del" => [2.2, 2.5, 2.9, 3.0],
        "sha" => [2.0, 2.4, 2.3, 2.7],
    )
    fig = Figure(size = (560, 320))
    ax = Axis(fig[1, 1]; xlabel = "longitude", ylabel = "latitude")
    s = scatter!(ax, [139.7, 77.2, 121.5], [35.7, 28.6, 31.2]; markersize = 16)
    pts = interactables(s; payloads = cities)
    nothing
end
@bind pick masque(fig, pts)
begin
    detail = Figure(size = (560, 240))
    dax = Axis(detail[1, 1]; title = isnothing(pick) ? "click a city" : pick.name)
    isnothing(pick) || lines!(dax, series[pick.id])
    detail
end

The detail cell uses pick, so it responds to each click but not to hovering. The same pick.id could filter a DataFrame or choose the data for a fit. The detail figure can be a Masque widget too.

To show the clicked point as selected in a second widget, pass it as that widget's selected=. Selection round-trip shows how.

Several axes in one figure

One masque call covers every axis in a figure. Each scatter gets its own layer id (:scatter, :scatter_2, and so on), so pick.layer tells you which panel was clicked. Hovering or clicking a point highlights it only on its own panel, even when another panel plots the same row of your data.

To highlight the same row on both panels, select it on both layers from a value i set in another cell, such as a slider. The value cannot come from this widget's own pick, for the reason given in Selection:

masque(fig; selected = Dict(:scatter => [i], :scatter_2 => [i]))

To link clicks between panels, put each panel in its own figure, as in the example at the top of this page.

Highlight a series across panels

Hovering a legend entry highlights every mark of its series, on every axis where the series appears. Clicking an entry sets pick to a LegendEvent, which another cell can use to filter your data. See Legend.

Notebook as text

Hover over a legend entry, and every point in that series highlights on both axes.

Label each scatter plot and put both in one Legend, so hovering over an entry highlights the series it names.

begin
    xs = [1.0, 2.0, 3.0, 4.0]
    ys = [2.0, 1.5, 3.0, 2.2]
    zs = [0.8, 2.5, 1.2, 3.1]
    fig = Figure(size = (700, 280))
    ax_xy = Axis(fig[1, 1]; xlabel = "x", ylabel = "y", title = "xy")
    ax_xz = Axis(fig[1, 2]; xlabel = "x", ylabel = "z", title = "xz")
    p_xy = scatter!(ax_xy, xs, ys; label = "xy", markersize = 18)
    p_xz = scatter!(ax_xz, xs, zs; label = "xz", markersize = 18)
    Legend(fig[1, 3], [p_xy, p_xz], ["xy", "xz"])
    nothing
end

In your own notebook, @bind pick saves a click on an entry in pick, but this page does not show that value.

@bind pick masque(fig)

Filter a table from a region

To select many points at once, drag a box. When you release an ROIInteractable with selects, it returns every point inside the box. If you bind that result to picks, another cell can take those rows from your table with df[picks, :], or create another plot from them. Brush a region shows how.

For what each click, release, and drag sets pick to, see Concepts.
