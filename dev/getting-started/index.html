Getting started

Make one scatter plot interactive, then show your own data in its tooltips.

Install

Load Masque and a Makie backend in a Pluto cell, and Pluto installs both for you:

using Masque, CairoMakie

Put each code block from these docs in its own cell.

Info

Masque works with CairoMakie and WGLMakie. If you load both, masque uses CairoMakie. See Backends to choose between them.

Make a figure interactive

Create a figure the way you normally would. End the cell with nothing, or Pluto shows a second, static copy of the figure:

begin
    xs = [1.0, 2.0, 3.0, 4.0]
    ys = [2.0, 1.0, 4.0, 3.0]
    fig = Figure(size = (560, 360))
    ax = Axis(fig[1, 1])
    scatter!(ax, xs, ys; markersize = 16)
    nothing
end

Pass the figure to masque and bind the result to a variable:

@bind sel masque(fig)

sel has one field for each plot you can click, named after the plot, so this figure's scatter is sel.scatter. Hover over a point to see its index, x, and y; hovering leaves sel as it was. Clicking a point stores it in sel.scatter, and cells that use sel respond to the change:

pick = sel.scatter
isnothing(pick) ? "click a point" : "point $(pick.index) at x = $(pick.x)"

pick is nothing until you click, then an ElementEvent, and pick.index is the clicked point's position in the data you plotted, so ys[pick] is its y. To have sel be the point itself, without the field, see What the @bind value holds.

masque(fig) works on scatters, lines, bars, heatmaps, polygons, text, legends, and colorbars. Plots masque(fig) makes interactive has the full list.

Show your own data

The default tooltip shows coordinates. To add your own fields, pass the scatter to interactables with one payloads entry per point. Replace the figure cell with this one:

Notebook as text
begin
    xs = [1.0, 2.0, 3.0, 4.0]
    ys = [2.0, 1.0, 4.0, 3.0]
    fig = Figure(size = (560, 360))
    ax = Axis(fig[1, 1])
    s = scatter!(ax, xs, ys; markersize = 16)
    points = [(name = "one",), (name = "two",), (name = "three",), (name = "four",)]
    pts = interactables(s; payloads = points)
    nothing
end

and pass pts to masque in the @bind cell:

Notebook as text

Hover over a point to see its name, then click it, and the last cell names the point you clicked.

@bind sel masque(fig, pts)

if isnothing(sel.scatter)
    "click a point"
else
    "$(sel.scatter.name) selected, y = $(sel.scatter.y)"
end
click a point

Hovering a point now shows its name, x, and y, and clicking it sets sel.scatter.name. Your fields are added to the point's own x and y, so you don't copy the coordinates into each entry. These cells were recorded from a real notebook (see Examples on this site).
