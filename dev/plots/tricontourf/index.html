tricontourf!

masque(fig) makes each filled region of a tricontourf! plot respond: hovering a region shows the two levels it lies between, and a click selects it and sends it to your notebook. Hover the regions below, then click one:

Notebook as text
using Masque, CairoMakie, Random
begin
    rng = Xoshiro(3)
    px = 10 .* rand(rng, 150)
    py = 6 .* rand(rng, 150)
    depth = [20 + 15 * exp(-((a - 4)^2 + (b - 3)^2) / 6) for (a, b) in zip(px, py)]

    fig = Figure(size = (520, 320))
    ax = Axis(fig[1, 1]; xlabel = "East (km)", ylabel = "North (km)")
    tc = tricontourf!(ax, px, py, depth; levels = 20:3:35)
    Colorbar(fig[1, 2], tc; label = "Depth (m)")
    nothing
end
@bind pick masque(fig; bind = tc)

pick

What a click returns

A click gives an ElementEvent with these fields. Here the figure passes the plot as bind, so pick is that event itself; with @bind sel masque(fig), it is sel.poly.

FieldWhat it holds
indexwhich region, in Makie's order
low, highthe levels the region lies between

One level can be several regions, and each region is its own mark with the same low and high.

Show your own data

Makie decides how many regions there are, so give a tooltip template rather than payloads. The template can use low and high:

Notebook as text
masque(fig, interactables(tc; tooltip = masque"<b>$(low:.0f) to $(high:.0f) m</b> deep"))

Tooltips lists what a template can do.

Supported axes

tricontourf! works on a 2D Axis.
