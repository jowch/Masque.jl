boxplot!

masque(fig) makes each box respond: hovering a box shows its category and quartiles, and a click selects it and sends it to your notebook. Only the box itself responds, not its whiskers or outliers. Hover the boxes below, then click one:

Notebook as text
using Masque, CairoMakie, Random, Statistics
begin
    rng = Xoshiro(2)
    route = repeat([1, 2, 3]; inner = 60)
    minutes = [randn(rng, 60) .+ 10; randn(rng, 60) .* 2 .+ 12; randn(rng, 60) .+ 9]
    minutes[[5, 70, 94, 150]] = [15.0, 20.0, 19.5, 4.0]

    fig = Figure(size = (520, 320))
    ax = Axis(fig[1, 1]; xticks = (1:3, ["Route A", "Route B", "Route C"]), ylabel = "Minutes")
    b = boxplot!(ax, route, minutes; show_outliers = true)
    nothing
end
@bind pick masque(fig; bind = b)

pick

What a click returns

A click gives an ElementEvent with these fields. Here the figure passes the box plot as bind, so pick is that event itself; with @bind sel masque(fig), it is sel.boxplot.

FieldWhat it holds
indexthe box's place from left to right, so 1 is the leftmost
xwhere the box sits on the axis: the value you passed in route, such as 2 for Route B (y for a horizontal box)
q1, median, q3the box's lower edge, middle line and upper edge

Show your own data

To show more than the quartiles, give each box a payload, one per box from left to right, and a tooltip template that uses its fields. The template can use the box's own fields, such as median, next to yours:

Notebook as text
routes = [
    (route = "A", stops = 12),
    (route = "B", stops = 18),
    (route = "C", stops = 9),
]
masque(fig, interactables(b; payloads = routes, tooltip = masque"<b>Route $(route)</b><br>$(stops) stops, median $(median:.1f) min"))

Tooltips lists what a template can do.

Make the outliers respond

Hovering an outlier shows nothing, because only the boxes respond. To see which trip an outlier is, add a PointInteractable at the outliers' positions, with a payload for each. Masque doesn't know where the outliers are drawn, so find them the way boxplot! does: a point is an outlier when it is more than 1.5 times the box's height beyond the box. radius sets how many pixels around each one respond:

Notebook as text
begin
    outliers = Point2f[]
    trips = []
    for r in 1:3
        rows = findall(route .== r)
        q1, q3 = quantile(minutes[rows], [0.25, 0.75])
        reach = 1.5 * (q3 - q1)
        for i in rows
            if minutes[i] < q1 - reach || minutes[i] > q3 + reach
                push!(outliers, Point2f(r, minutes[i]))
                push!(trips, (trip = i,))
            end
        end
    end
    masque(fig, PointInteractable(ax, outliers; radius = 6, payloads = trips, id = :outliers))
end

Hovering an outlier now shows its trip number, and a click on one sets the outliers field of the @bind value. The boxes keep their hover.

Supported axes

boxplot! works on a 2D Axis. On an Axis3 or a PolarAxis, it is skipped with a warning.
