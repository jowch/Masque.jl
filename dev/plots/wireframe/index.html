wireframe!

On an Axis3, masque(fig) makes each edge of a wireframe! respond: hovering an edge shows its two ends, and a click selects it and sends it to your notebook. Hover the mesh below, then click an edge:

Notebook as text
using Masque, CairoMakie, Random
begin
    xs = range(-2, 2; length = 9)
    ys = range(-2, 2; length = 9)
    zs = [exp(-(x^2 + y^2) / 2) for x in xs, y in ys]

    fig = Figure(size = (520, 380))
    ax = Axis3(
        fig[1, 1];
        xlabel = "x (km)",
        ylabel = "y (km)",
        zlabel = "Height (km)",
    )
    wf = wireframe!(ax, xs, ys, zs; color = :steelblue)
    nothing
end
@bind pick masque(fig; bind = wf)

pick

What a click returns

A click gives an ElementEvent with these fields. Here the figure passes the plot as bind, so pick is that event itself; with @bind sel masque(fig), it is sel.wireframe.

FieldWhat it holds
segment_indexwhich edge, in Makie's order
x1, y1, z1, x2, y2, z2the edge's two ends

Show your own data

Makie decides the order of the edges, so give a tooltip template rather than payloads. The template can use the ends:

Notebook as text
masque(
    fig,
    interactables(
        wf;
        tooltip = masque"edge from $(z1:.2f) to $(z2:.2f) km high",
    ),
)

Tooltips lists what a template can do.

Supported axes

wireframe! works on an Axis3. Drawn over a surface! of the same grid, it is left as decoration and the surface responds.
