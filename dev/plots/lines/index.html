lines!

masque(fig) makes each line respond: hovering a line shows the point you plotted nearest the pointer. A click changes nothing until you name the line in bind; then a click picks that same point, a ring marks it, and it goes to your notebook. Here both lines are named, so each gets its own field. Hover a line below, then click it:

Notebook as text
using Masque, CairoMakie, Random
begin
    hour = 0:23
    berlin = round.(12 .+ 6 .* sin.((hour .- 9) .* π ./ 12); digits = 1)
    oslo = round.(8 .+ 4 .* sin.((hour .- 9) .* π ./ 12); digits = 1)

    fig = Figure(size = (520, 320))
    ax = Axis(
        fig[1, 1];
        xlabel = "Hour",
        ylabel = "Temperature (°C)",
        xticks = 0:6:24,
    )
    l1 = lines!(ax, hour, berlin; label = "Berlin")
    l2 = lines!(ax, hour, oslo; label = "Oslo")
    nothing
end
@bind sel masque(fig; bind = (berlin = l1, oslo = l2))

sel

What a click returns

With bind = (berlin = l1, oslo = l2), sel.berlin and sel.oslo each hold nothing or the point clicked on that line, as an ElementEvent with these fields:

FieldWhat it holds
indexthe point's place in your data, so hour[sel.berlin.index] reads it
linewhich line of the plot, always 1 for a lines!
x, ythe point you plotted, and z on an Axis3

To keep a click on several points, pass select = :many to the line's interactables; each click then adds a point. To make a line clickable while keeping every other plot's field in the @bind value, pass interactables(l1) after the figure instead of naming it in bind.

Show your own data

A line is one mark, so it takes one payload: a list with one entry. The tooltip template can use the hovered point's x and y next to your fields:

Notebook as text
masque(
    fig,
    interactables(
        l1;
        payloads = [(city = "Berlin",)],
        tooltip = masque"<b>$(city)</b><br>$(y) °C at $(x):00",
    ),
    interactables(
        l2;
        payloads = [(city = "Oslo",)],
        tooltip = masque"<b>$(city)</b><br>$(y) °C at $(x):00",
    ),
)

Tooltips lists what a template can do.

Read every line at the same x

To compare the lines at one hour, add a SliceInteractable over them. Its tooltip lists every line's value where the pointer is, using the lines' labels:

Notebook as text
masque(fig, SliceInteractable([l1, l2]))

Slice across series shows how to use the slice's click.

Supported axes

lines! works on a 2D Axis, an Axis3 and a PolarAxis.

Where to go next

To draw many lines with one call, see series!. To show the points as markers too, see scatterlines!.
