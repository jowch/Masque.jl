barplot!

masque(fig) makes each bar respond: hovering a bar shows its value and where it starts and ends, and a click selects it and sends it to your notebook. Hover the bars below, then click one:

Notebook as text
using Masque, CairoMakie, Random
begin
    fruit = ["Apples", "Pears", "Plums", "Figs"]
    sold = [42, 31, 18, 25]

    fig = Figure(size = (520, 320))
    ax = Axis(fig[1, 1]; xticks = (1:4, fruit), ylabel = "Crates sold")
    b = barplot!(ax, 1:4, sold)
    nothing
end
@bind pick masque(fig; bind = b)

pick

What a click returns

A click gives an ElementEvent with these fields. Here the figure passes the bar plot as bind, so pick is that event itself; with @bind sel masque(fig), it is sel.bars.

FieldWhat it holds
indexthe bar's place in your data, so 1 is the first value you passed
xthe bar's category: the x you passed for it, or its tick label
valuethe bar's height: high minus low
low, highwhere the bar starts and ends along its value axis

For bars drawn with direction = :x, the category is y, and low and high are measured along x. Makie puts the labels of Categorical input on the x axis even then, so for those bars y is the bar's number on the y axis.

Show your own data

To show what the axis can't, such as where each fruit is sold, give each bar a payload, one per bar in the order of your data, and a tooltip template that uses its fields. The template can use the bar's own fields, such as value, next to yours:

Notebook as text
stalls = [
    (fruit = "Apples", stall = "North gate"),
    (fruit = "Pears", stall = "Bridge"),
    (fruit = "Plums", stall = "North gate"),
    (fruit = "Figs", stall = "Square"),
]
masque(fig, interactables(b; payloads = stalls, tooltip = masque"<b>$(fruit)</b><br>$(value) crates at $(stall)"))

A click also returns the payload's fields, so pick.fruit is the name of the bar you clicked. Tooltips lists what a template can do.

Stacked and dodged bars

Each segment of a stacked bar, and each bar of a dodged group, is its own mark. index says which segment was hovered or clicked, x names its category, and low and high say where it sits on the stack. The payloads follow the order of your data, so one per row:

Notebook as text
begin
    quarter = repeat(1:4; outer = 2)
    product = repeat([1, 2]; inner = 4)
    sales = [5, 7, 6, 8, 3, 2, 4, 3]

    fig2 = Figure(size = (520, 320))
    ax2 = Axis(fig2[1, 1]; xticks = (1:4, ["Q1", "Q2", "Q3", "Q4"]), ylabel = "Sales")
    b2 = barplot!(ax2, quarter, sales; stack = product, color = product)
    nothing
end
masque(
    fig2, interactables(
        b2;
        payloads = [(product = p == 1 ? "Tea" : "Coffee",) for p in product],
        tooltip = masque"<b>$(product)</b><br>$(value) sold, from $(low) to $(high)",
    )
)

Supported axes

barplot! works on a 2D Axis. On an Axis3 or a PolarAxis, it is skipped with a warning. Bars turned with rotate! are skipped too; to make rotated bars respond, draw them with poly!.
