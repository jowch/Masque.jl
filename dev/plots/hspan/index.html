hspan! and vspan!

masque(fig) makes each span respond: hovering a span shows where it starts and ends, and a click selects it and sends it to your notebook. A vspan! marks a range of x, and an hspan! a range of y. Hover the two shaded periods below, then click one:

Notebook as text
using Masque, CairoMakie, Random
begin
    rng = Xoshiro(5)
    day = 1:100
    price = 100 .+ cumsum(randn(rng, 100))

    fig = Figure(size = (520, 320))
    ax = Axis(fig[1, 1]; xlabel = "Day", ylabel = "Price")
    lines!(ax, day, price; color = :gray40)
    s = vspan!(ax, [20, 62], [31, 75]; color = (:orange, 0.25))
    nothing
end
@bind pick masque(fig; bind = s)

pick

A span covers the whole axis in the other direction, and after you pan or zoom it still does.

What a click returns

A click gives an ElementEvent with these fields. Here the figure passes the spans as bind, so pick is that event itself; with @bind sel masque(fig), it is sel.vspan, or sel.hspan for an hspan!.

FieldWhat it holds
indexthe span's place in your data, so 1 is the first range you passed
low, highwhere the span starts and ends: on x for a vspan!, on y for an hspan!

Show your own data

To say what each period was, give each span a payload, one per span in the order of your data, and a tooltip template that uses its fields:

Notebook as text
masque(
    fig, interactables(
        s;
        payloads = [(event = "Recall",), (event = "Strike",)],
        tooltip = masque"<b>$(event)</b><br>day $(low) to day $(high)",
    )
)

A click also returns the payload's fields, so pick.event is the name of the period you clicked. Tooltips lists what a template can do.

Supported axes

hspan! and vspan! work on a 2D Axis, the only axis Makie draws them on.

Where to go next
