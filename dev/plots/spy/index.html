spy!

masque(fig) makes each entry of a spy! plot respond: hovering an entry shows its place in your matrix and its value, and a click selects it and sends it to your notebook. Only the entries spy! draws, the nonzero ones, respond. Hover the entries below, then click one:

Notebook as text
using Masque, CairoMakie, Random
begin
    rng = Xoshiro(5)
    links = [rand(rng) < 0.08 ? round(rand(rng); digits = 2) : 0.0 for _ in 1:20, _ in 1:20]

    fig = Figure(size = (520, 360))
    ax = Axis(fig[1, 1]; aspect = DataAspect(), yreversed = true, title = "Links between 20 pages")
    sp = spy!(ax, links; colormap = :viridis)
    nothing
end
@bind pick masque(fig; bind = sp)

pick

What a click returns

A click gives an ElementEvent with these fields. Here the figure passes the plot as bind, so pick is that event itself; with @bind sel masque(fig), it is sel.spy.

FieldWhat it holds
indexwhich entry, counting the nonzero entries column by column
i, jthe entry's first and second index in your matrix; Makie draws the first along x
valuethe entry's value

links[pick.i, pick.j] reads the same entry from your matrix.

Show your own data

A tooltip template can use i, j and value:

Notebook as text
masque(fig, interactables(sp; tooltip = masque"page $(i) → page $(j)<br>weight $(value:.2f)"))

Tooltips lists what a template can do.

Supported axes

spy! works on a 2D Axis.
