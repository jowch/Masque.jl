text!

masque(fig) makes each label of a text! respond over the box its text takes up: hovering a label shows its text and position, and a click selects it and sends it to your notebook. Hover the city names below, then click one:

Notebook as text
using Masque, CairoMakie
begin
    cities = ["Lisbon", "Madrid", "Paris", "Berlin", "Rome", "Vienna"]
    lon = [-9.1, -3.7, 2.4, 13.4, 12.5, 16.4]
    lat = [38.7, 40.4, 48.9, 52.5, 41.9, 48.2]

    fig = Figure(size = (520, 320))
    ax = Axis(
        fig[1, 1];
        xlabel = "Longitude",
        ylabel = "Latitude",
        limits = (-14, 21, 36, 56),
    )
    scatter!(ax, lon, lat; color = :gray60, markersize = 6)
    t = text!(
        ax, lon, lat;
        text = cities,
        align = (:center, :bottom),
        offset = (0, 4),
    )
    nothing
end
@bind pick masque(fig; bind = t)

pick

The grey markers under the names respond too, as a scatter!.

What a click returns

A click gives an ElementEvent with these fields. Here the figure passes the labels as bind, so pick is that event itself; with @bind sel masque(fig), it is sel.text.

FieldWhat it holds
indexthe label's place in your data, so cities[pick.index] reads it
textthe label's text
x, ywhere you placed it, and z on an Axis3

Show your own data

Give each label a payload, one per label in the order of your data, and a tooltip template that uses its fields. The template can use the label's own text:

Notebook as text
masque(
    fig,
    interactables(
        t;
        payloads = [(people = p,) for p in [0.5, 3.3, 2.1, 3.7, 2.8, 2.0]],
        tooltip = masque"<b>$(text)</b><br>$(people) million people",
    ),
)

Tooltips lists what a template can do.

Supported axes

text! works on a 2D Axis and an Axis3. On a PolarAxis, it is skipped with a warning. Text placed in pixels or relative to the axis, rather than in data, is skipped with a warning too.
