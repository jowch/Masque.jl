density!

masque(fig) makes each density curve respond as one filled area: hovering it highlights the curve and shows its index, and a click selects it and sends it to your notebook. Hover the curves below, then click one:

Notebook as text
using Masque, CairoMakie, Random
begin
    rng = Xoshiro(4)
    fig = Figure(size = (520, 320))
    ax = Axis(fig[1, 1]; xlabel = "Height (cm)")
    d1 = density!(ax, randn(rng, 200) .* 7 .+ 165; color = (:steelblue, 0.5))
    d2 = density!(ax, randn(rng, 200) .* 7 .+ 178; color = (:orange, 0.5))
    nothing
end
@bind sel masque(fig)

sel

What a click returns

Each density! is one mark with its own field in the @bind value: sel.density for the first, then sel.density_2, sel.density_3. A click gives an ElementEvent whose index is 1, since each plot has one curve. Where two curves overlap, the one drawn last answers.

Show your own data

The field name alone doesn't say which group a curve is. To name each curve, give each plot one payload and a tooltip template:

Notebook as text
masque(
    fig,
    interactables(
        d1;
        payloads = [(group = "Women", n = 200)],
        tooltip = masque"<b>$(group)</b>, $(n) people",
    ),
    interactables(
        d2;
        payloads = [(group = "Men", n = 200)],
        tooltip = masque"<b>$(group)</b>, $(n) people",
    ),
)

A click also returns the payload's fields, so sel.density.group is "Women". Tooltips lists what a template can do.

Read the value under the pointer

Hovering a curve shows its group, not the height under the pointer. To read the height anywhere on the axis, add an AxisInteractable and pass auto = false. Without it, a curve answers wherever the pointer is over one, so the axis would only read between them. With it, the curves no longer respond on their own:

Notebook as text
masque(fig, AxisInteractable(ax); auto = false)

Supported axes

density! works on a 2D Axis.
