violin!

masque(fig) makes each violin respond on its own: hovering a violin shows its category, the tick label under it, and a click selects it and sends it to your notebook. Hover the violins below, then click one:

Notebook as text
using Masque, CairoMakie, Random, Statistics
begin
    rng = Xoshiro(1)
    groups = repeat([1, 2, 3]; inner = 100)
    weights = [randn(rng, 100) .+ 4; randn(rng, 100) .+ 5; randn(rng, 100) .+ 4.5]

    fig = Figure(size = (520, 320))
    ax = Axis(fig[1, 1]; xticks = (1:3, ["Adelie", "Chinstrap", "Gentoo"]), ylabel = "Weight (kg)")
    v = violin!(ax, groups, weights)
    nothing
end
@bind pick masque(fig; bind = v)

pick

What a click returns

A click gives an ElementEvent with two fields. Here the figure passes the violin plot as bind, so pick is that event itself; with @bind sel masque(fig), it is sel.violin.

FieldWhat it holds
indexthe violin's place from left to right, so 1 is the leftmost
xwhere the violin sits on the axis: the value you passed in groups, such as 2 for Chinstrap

A horizontal violin, drawn with orientation = :horizontal, reports its category as y instead of x.

Show your own data

To show what the axis can't, such as how many penguins each violin holds and their median weight, give each violin a payload, one per violin from left to right, and a tooltip template that uses its fields:

Notebook as text
summary = [
    (species = "Adelie", n = 100, median = round(median(weights[groups .== 1]); digits = 1)),
    (species = "Chinstrap", n = 100, median = round(median(weights[groups .== 2]); digits = 1)),
    (species = "Gentoo", n = 100, median = round(median(weights[groups .== 3]); digits = 1)),
]
masque(fig, interactables(v; payloads = summary, tooltip = masque"<b>$(species)</b><br>$(n) birds, median $(median) kg"))

A click also returns the payload's fields, so pick.species is the name of the violin you clicked. Tooltips lists what a template can do.

Select several violins

To compare groups, pass select = :many. Each click then adds a violin to the selection or takes it out again:

Notebook as text
masque(fig, interactables(v; select = :many))

With @bind sel in front, sel.violin is then a vector of events, one per selected violin. See Select several marks.

Read the value under the pointer

Hovering a violin shows the whole group, not the weight at the pointer. To read the weight anywhere on the axis, add an AxisInteractable and pass auto = false. Without it, a violin answers wherever the pointer is over one, so the axis would only read between them. With it, the violins no longer respond on their own:

Notebook as text
masque(fig, AxisInteractable(ax); auto = false)

Supported axes

violin! works on a 2D Axis. On an Axis3 or a PolarAxis, it is skipped with a warning.
