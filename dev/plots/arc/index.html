arc!

masque(fig) makes each arc! respond along its whole length: hovering an arc shows the point on it nearest the pointer. A click changes nothing until you name the arc in bind; then a click picks that point and sends it to your notebook. Here both arcs are named, so each gets its own field. Hover an arc below, then click it:

Notebook as text
using Masque, CairoMakie, Random
begin
    fig = Figure(size = (520, 320))
    ax = Axis(
        fig[1, 1];
        aspect = DataAspect(),
        xlabel = "x (m)",
        ylabel = "y (m)",
    )
    a1 = arc!(ax, Point2f(0, 0), 1, 0, π; linewidth = 3)
    a2 = arc!(ax, Point2f(0, 0), 2, 0, π / 2; linewidth = 3, color = :orange)
    nothing
end
@bind pick masque(fig; bind = (inner = a1, outer = a2))

pick

What a click returns

With bind = (inner = a1, outer = a2), pick.inner and pick.outer each hold nothing or the point clicked on that arc, as an ElementEvent with these fields:

FieldWhat it holds
indexthe point's place along the arc as Makie draws it
linealways 1
x, ythe point on the arc

Makie draws an arc from many short pieces, so index counts those, not anything you passed.

Show your own data

An arc is one mark, so it takes a list with one payload. Give each arc its own interactables call, with its payload and a tooltip template:

Notebook as text
masque(
    fig,
    interactables(
        a1;
        payloads = [(name = "Inner track", radius = 1)],
        tooltip = masque"<b>$(name)</b><br>radius $(radius) m",
    ),
    interactables(
        a2;
        payloads = [(name = "Outer track", radius = 2)],
        tooltip = masque"<b>$(name)</b><br>radius $(radius) m",
    ),
)

Tooltips lists what a template can do.

Supported axes

arc! works on a 2D Axis.
