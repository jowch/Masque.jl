scatterlines!

A scatterlines! plot has two parts: the points, and the line through them. masque(fig) makes each point respond: hovering one shows it, and a click selects it and sends it to your notebook, with no bind needed. The line shows its own tooltip but takes no click. Hover the points below, then click one:

Notebook as text
using Masque, CairoMakie, Random
begin
    month = 1:8
    visitors = [120, 135, 160, 158, 190, 240, 260, 230]

    fig = Figure(size = (520, 320))
    ax = Axis(fig[1, 1]; xlabel = "Month", ylabel = "Visitors", xticks = 1:8)
    sl = scatterlines!(ax, month, visitors)
    nothing
end
@bind sel masque(fig)

sel

What a click returns

The parts sit under the plot's name in the @bind value, so a click on a point is sel.scatterlines.points, an ElementEvent with these fields:

FieldWhat it holds
indexthe point's place in your data, so 1 is the first
x, ythe point you plotted

Show your own data

Give the points a payload each, under the part's name, points. The tooltip then shows your fields next to the point's own:

Notebook as text
events = [
    (month = m, event = e) for (m, e) in zip(
            ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug"],
            ["none", "none", "Fair", "none", "none", "Festival", "Festival", "none"],
        )
]
masque(fig, interactables(sl; payloads = (points = events,)))

A click also returns the payload, so sel.scatterlines.points.event is the event of the month you clicked. Plots with several parts says how payloads work for each part.

Supported axes

scatterlines! works on a 2D Axis, an Axis3 and a PolarAxis.
