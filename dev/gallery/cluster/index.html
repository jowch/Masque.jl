Compare a cluster

Drag a box around a group of points to see what is different about it. In this clip, the box starts on one cluster, moves to the other, then shrinks to cover half of it. The count beside the box updates as it moves, and after each release, the histogram under the scatter compares the z of the points in the box with all the samples.

First, create the scatter and the box:

begin
    using Random
    Random.seed!(3)   # the same samples every time the notebook runs

    # 80 samples in one cluster, then 70 in another
    xs = [3.0 .+ 0.9 .* randn(80); 7.0 .+ 0.9 .* randn(70)]
    ys = [3.0 .+ 0.9 .* randn(80); 6.0 .+ 0.8 .* randn(70)]
    zs = [1.2 .+ 0.3 .* randn(80); 2.8 .+ 0.35 .* randn(70)]

    fig = Figure(size = (560, 360))
    ax = Axis(fig[1, 1]; xlabel = "x", ylabel = "y", title = "drag the box over a cluster")
    s = scatter!(ax, xs, ys; color = zs, colormap = :viridis, markersize = 9)

    samples = [(sample = i, x = xs[i], y = ys[i], z = zs[i]) for i in 1:150]
    pts = interactables(
        s;
        id = :pts,
        payloads = samples,
        tooltip = masque"sample $(sample)<br>x $(x:.2f), y $(y:.2f), z $(z:.2f)",
    )
    roi = ROIInteractable(ax; bounds = (5.2, 9.2, 4.4, 7.8), selects = :pts)
    nothing
end

Then show the figure and bind the points that the box selects:

@bind picks masque(fig, pts, roi)

Finally, compare the points inside the box with every sample:

begin
    edges = range(minimum(zs), maximum(zs); length = 21)
    inside = zs[picks]
    cmp = Figure(size = (560, 260))
    cax = Axis(
        cmp[1, 1]; xlabel = "z", ylabel = "samples",
        title = isempty(inside) ? "all samples" : "$(length(inside)) samples in the box, against all $(length(zs))"
    )
    hist!(cax, zs; bins = edges, color = (:gray, 0.45), label = "all")
    if !isempty(inside)
        hist!(cax, inside; bins = edges, color = (:darkorange, 0.85), label = "in the box")
    end
    axislegend(cax; position = :rt)
    cmp
end

How it works

Each point's payload carries its three measurements, and the template rounds them to two decimals, so hovering over a point shows them. The ROIInteractable names the points' layer with selects = :pts, so when you release the box, picks is a vector with one event per point inside. Index your data with it: zs[picks] is the z of the points in the box.

Variations

  • Keep your samples in a DataFrame and pass it as payloads. Then df[picks, :] is the rows inside the box. Before the first release, picks is nothing, so check for it as Brush a region shows.
  • Replace the histogram with whatever the comparison needs: a table of means, a second scatter of two other columns, or a model fitted to the selected points only.
