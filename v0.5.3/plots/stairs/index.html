stairs!

masque(fig) makes a staircase respond like a line: hovering it shows the step you plotted nearest the pointer. Pass the plot as bind and a click picks that step and sends it to your notebook. Hover the staircase below, then click a step:

Notebook as text
using Masque, CairoMakie, Random
begin
    day = 1:10
    staff = [2, 2, 3, 5, 5, 4, 6, 6, 7, 7]

    fig = Figure(size = (520, 320))
    ax = Axis(fig[1, 1]; xlabel = "Day", ylabel = "Staff on shift")
    st = stairs!(ax, day, staff; step = :post)
    nothing
end
@bind pick masque(fig; bind = st)

pick

What a click returns

A click gives an ElementEvent with these fields. Here the figure passes the staircase as bind, so pick is that event itself; with @bind sel masque(fig; bind = (staff = st,)), it is sel.staff.

FieldWhat it holds
indexthe step's place in your data, so day[pick.index] reads it
linealways 1
x, ythe point you plotted for that step

Show your own data

A staircase is one mark, so it takes one payload: a list with one entry. The tooltip template can use the hovered step's x and y next to your fields:

Notebook as text
masque(
    fig, interactables(
        st;
        payloads = [(team = "Kitchen",)],
        tooltip = masque"<b>$(team)</b><br>$(y) on shift from day $(x)",
    )
)

Tooltips lists what a template can do.

Supported axes

stairs! works on a 2D Axis. On an Axis3 or a PolarAxis, it is skipped with a warning.

Where to go next
