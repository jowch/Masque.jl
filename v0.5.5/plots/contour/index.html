contour!

masque(fig) makes a contour plot respond like one line: hovering any contour shows the point nearest the pointer. Pass the plot as bind and a click picks that point and sends it to your notebook. Hover a contour below, then click one:

Notebook as text
using Masque, CairoMakie, Random
begin
    xs = range(-3, 3; length = 60)
    ys = range(-2, 2; length = 40)
    height = [exp(-(x^2 + 2y^2) / 3) * 100 for x in xs, y in ys]

    fig = Figure(size = (520, 320))
    ax = Axis(fig[1, 1]; xlabel = "East (km)", ylabel = "North (km)")
    c = contour!(ax, xs, ys, height; levels = 10:20:90)
    nothing
end
@bind pick masque(fig; bind = c)

pick

What a click returns

A click gives an ElementEvent with these fields. Here the figure passes the plot as bind, so pick is that event itself; with @bind sel masque(fig; bind = (hill = c,)), it is sel.hill.

FieldWhat it holds
indexthe point's place along all the contours together
linealways 1: every contour is one mark
x, ythe point on the contour

The click doesn't say which level the contour is.

Read the level from the labels

Draw the contours with labels = true, and each label responds on its own: hovering one shows its text, the level, and a click on it returns its text, index, x and y. The lines and the labels are then two parts; see Plots with several parts:

Notebook as text
begin
    fig2 = Figure(size = (520, 320))
    ax2 = Axis(fig2[1, 1]; xlabel = "East (km)", ylabel = "North (km)")
    contour!(ax2, xs, ys, height; levels = 10:20:90, labels = true)
    masque(fig2)
end

Supported axes

contour! works on a 2D Axis, and contour3d! on an Axis3.

Where to go next

For filled levels, where each region is its own mark, see contourf!.
